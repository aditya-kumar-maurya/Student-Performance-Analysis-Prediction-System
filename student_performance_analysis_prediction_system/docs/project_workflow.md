# Project Workflow

1. Collect 500 synthetic student records.
2. Store raw records in CSV.
3. Clean missing and incorrect values with Pandas.
4. Perform numerical processing with NumPy/Pandas.
5. Analyze academic performance.
6. Generate Matplotlib and Seaborn visualizations.
7. Store cleaned records in SQLite.
8. Use SQL SELECT queries for student records and dashboard metrics, and INSERT queries for prediction history.
9. Split data into training and testing sets.
10. Train Random Forest Regression with Scikit-learn.
11. Evaluate using MAE, RMSE and R².
12. Save the trained model with Joblib.
13. Load the model in Flask.
14. Accept student information from the web form.
15. Predict final score.
16. Save each prediction to SQLite.
17. Display dashboard, student analysis and prediction history.
