# 🎓 Student Performance Analysis & Prediction System

A Flask-based web application for analyzing student academic performance and predicting final scores using Machine Learning.

## 🚀 Key Features

- 📊 Student Performance Dashboard
- 📈 Performance Analytics & Visualizations
- 🤖 Final Score Prediction using Random Forest Regression
- 👨‍🎓 Student Analysis
- 💡 Performance Insights
- 🗃️ SQLite-based Student Management
- ➕ Add Student
- ✏️ Edit Student
- 🗑️ Delete Student
- 📥 CSV Import
- 🕒 Prediction History
- 📊 Matplotlib & Seaborn Charts
- 🌙 Dark Mode UI

## 🛠️ Technologies Used

Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Random Forest Regression, Flask, SQLite, SQL, HTML, CSS and JavaScript.
